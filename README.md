## Run Locally

Since the website uses standard frontend technologies, you can run it locally without installing a frontend framework.

1. Clone the repository:

   ```bash
   git clone https://github.com/boikzdev/boikuntha-portfolio.git
   ```

2. Open the project directory:

   ```bash
   cd boikuntha-portfolio
   ```

3. Open `index.html` in your browser, or use a local development server for a more consistent testing experience.

## Deployment

The website is deployed using Cloudflare and can be connected to a GitHub repository for a streamlined deployment workflow.

For future updates:

1. Commit and push changes to GitHub.
2. Connect the repository to the appropriate Cloudflare project.
3. Configure the deployment branch and output settings.
4. Verify the live website after deployment.

The exact deployment configuration depends on the Cloudflare project type.
